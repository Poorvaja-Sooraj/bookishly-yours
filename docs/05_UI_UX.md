# 1. Design Philosophy

The interface should feel like opening a personal reading journal rather than using a productivity application.

The overall experience should be:

* Warm
* Elegant
* Calm
* Cozy
* Minimal
* Emotional

The interface should encourage readers to slow down and enjoy revisiting their memories.

---

# 2. Design Theme

### Primary Theme

A modern bookshelf combined with a personal journal.

The application should avoid looking like:

* Goodreads
* Notion
* Excel
* Dashboard software

Instead it should feel like:

* Opening a favorite book
* Browsing a personal diary
* Sitting in a cozy reading corner

---

---

# 11. Reading Journey Popup ⭐

This is the signature screen.

It opens as a large centered popup.

Background becomes blurred.

The popup contains a single continuous scroll.

Contents:

* Cover Image
* Book Title
* Author
* Reading Progress
* Started Date
* Finished Date
* Reading Time
* Reading Sessions
* Timeline of:
  * Thoughts
  * Voice Notes
  * Photos
  * Quotes
* Reflection
* Rating

No tabs.

No multiple pages.

Everything should feel like reading a journal.

---

# 12. Reading Mode

When Start Reading is pressed:

Display:

* Current Page
* Timer
* Pause
* Stop

Nothing else.

Distraction free.

---

# 13. Pause Screen

Pause should display:

* Add Thought
* Add Voice
* Add Photo
* Resume Reading

After capturing something:

Preview:

✓ Confirm

✗ Discard

Then Resume.

---

# 14. Search

Instant search.

Supports:

* Title
* Author
* Genre

Future:

OCR Quote Search.

---

# 15. Animations

Use subtle animations.

Examples:

* Card hover
* Popup fade
* Smooth scrolling
* Soft transitions

Avoid flashy effects.

---

# 16. Responsive Design

Desktop First.

Tablet supported.

Mobile supported.

The layout should adapt without changing the core experience.

---

# 17. Accessibility

Readable fonts.

High contrast.

Keyboard navigation.

Large clickable buttons.

---

# 18. UI Principles

Every screen should answer:

> Does this help the reader relive the journey?

If not, remove it.
